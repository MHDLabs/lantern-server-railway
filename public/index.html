Never mistake it for a VPN.

A small, secure control panel hosted on Cloudflare. The original Lantern proxy data plane cannot run on Workers, so this edition does not provide VPN connectivity or Lantern client configurations.

!
Official Lantern protocol is not supported here

Workers have no public inbound TCP/UDP listener. The original server relies on lantern-box to accept Shadowsocks and other proxy traffic. This panel never returns a fake connection config.
